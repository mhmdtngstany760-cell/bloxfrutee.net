# بسته آماده‌سازی سایت برای درخواست اینماد

این بسته روی فایل‌های ارسال‌شده کار می‌کند و طراحی اصلی صفحه فروشگاه را حفظ می‌کند.

## فایل‌ها
- `index.html`: صفحه اصلی؛ تصویر/نمایش گمراه‌کننده اینماد با توضیح شفاف «در حال آماده‌سازی» جایگزین شده است.
- `style.css`: استایل اصلی و استایل صفحات قانونی.
- `about.html`: درباره فروشگاه و تماس.
- `terms.html`: قوانین خرید و تحویل.
- `returns.html`: لغو سفارش و بازپرداخت.
- `privacy.html`: حریم خصوصی.
- `script.js` و `supabase-config.js`: فایل‌های ارسالی شما؛ بدون ادعای تکمیل یا بررسی امنیتی.

## قبل از انتشار
1. تمام متن‌های داخل `[کروشه]` و بخش‌های زرد را با اطلاعات واقعی تکمیل کن.
2. لینک‌ها، ایمیل، ساعت پاسخ‌گویی، واحد قیمت و شیوه تحویل را بررسی کن.
3. قوانین را با نوع واقعی فعالیت و مقررات مربوط به آن تطبیق بده.
4. فایل‌ها را در ریشه همان مخزن GitHub Pages کنار هم قرار بده.
5. این بسته به معنی صدور اینماد نیست. تا وقتی نماد برای همان دامنه صادر نشده، نشان رسمی اینماد را نمایش نده.
6. در نسخه فعلی، قیمت‌ها و سفارش‌ها ممکن است از سمت مرورگر قابل دستکاری باشند. برای فروش واقعی، سفارش و پرداخت باید با بک‌اند امن و سیاست‌های دسترسی درست پیاده‌سازی شوند.

## نکته فنی
`index.html` در نسخه ارسالی بخشی از JavaScript را داخل خودش دارد و `script.js` جداگانه نیز وجود دارد. این بسته فایل جداگانه را حذف نمی‌کند؛ پیش از توسعه بیشتر باید مشخص شود کدام نسخه اسکریپت واقعاً استفاده می‌شود.

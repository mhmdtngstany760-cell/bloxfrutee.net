# Fruit Market - GitHub version

این نسخه بر پایه فایل‌های ارسالی شما ساخته شده است.

امکانات اضافه‌شده:
- ورود پنل Admin فقط بعد از کلیک روی Admin
- رمز پنل: `3530387411`
- افزودن میوه از داخل پنل
- تعیین قیمت و موجودی
- تغییر قیمت و موجودی
- حذف محصول
- نمایش موجودی روی کارت محصول
- جلوگیری از ثبت خرید بیشتر از موجودی
- ذخیره محصولات و موجودی در localStorage همین مرورگر

توجه: این نسخه هنوز دیتابیس مشترک ندارد. برای اینکه سفارش و تغییرات محصولات از هر دستگاهی برای همه کاربران مشترک باشد، باید Backend/Database (مثل Supabase) متصل شود. همچنین رمز داخل JavaScript برای سایت عمومی امنیت واقعی محسوب نمی‌شود.
